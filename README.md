# Bharat Institute of Technology

BIT is a dependency-free static institute website with a 3D learning experience, course catalogue, admin-only certificate studio, QR certificate verification, and responsive layouts.

## Run locally

Open `index.html` in a modern browser, or serve this folder with any static web server.

## Important note

Course outlines are proposed demo content. Certificate records in this front-end demo are stored in the current browser only; connect a secure server database and authentication before real-world use.
